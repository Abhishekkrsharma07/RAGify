# RAGify — Intelligent Document Q&A with RAG

RAGify is a production-focused **Retrieval-Augmented Generation (RAG)** project that transforms static PDFs into an interactive AI knowledge assistant.  
It lets users upload documents, ask natural-language questions, and receive fast, context-aware answers grounded in the source content.

## Why RAGify stands out

- **Business-ready use case**: Turns unstructured documents into searchable intelligence.
- **Accurate by design**: Combines semantic retrieval with LLM reasoning to reduce hallucinations.
- **User-centric experience**: Natural conversation flow for non-technical users.
- **Modern AI stack**: Built with proven tools used in real-world GenAI products.

## Core capabilities

- PDF ingestion and text chunking
- Vector indexing for semantic similarity search
- Context retrieval pipeline for relevant passages
- LLM-powered answer generation with source grounding
- Chat-style interface for iterative follow-up questions

## Tech Stack

- **Frontend**: React
- **Backend**: Flask
- **Retrieval Layer**: FAISS, LangChain
- **LLM**: Google Gemini
